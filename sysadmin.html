Locked out of Authenticator?

There is no self-service reset for the single staff account. In Firebase Console → Authentication → find the staff user → remove the second factor, then sign in again and re-enroll. Keep the setup key from above stored safely to avoid this.

Stray accounts

If anyone ever created an extra email/password account, it can sign in to Firebase but this portal signs it straight back out and it cannot read submissions. Delete unknown users in Firebase Console → Authentication → Users.
